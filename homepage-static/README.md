# homepage-static — новая главная страница (статический экспорт, 12.11.2026)

Пересобранная главная («небесный hero, выбор ситуации вместо прайса, слайдер врачей
с описаниями», блок «Почему к нам» с автогалереей; убраны шаги, акции и отзывы —
отзывы вынесены в меню). Экспорт внешнего сборщика, манифест — `github.md`.

## Файлы
- `index.html` — новая главная (использует ТЕ ЖЕ `/_astro/*.css` и шрифты, что и весь сайт)
- `support.js` — скрипт страницы
- `img/` — переопределения/дополнения: `licenses/lic1.webp`, `gallery/hall.webp` (новые),
  `logo.svg`/`logo-white.svg` (визуально идентичны текущим), `doctors/*`, `gallery/*` — копии
- `github.md` — манифест экспорта (repo: uShure/ushure.github.io)

## Как применить (посЛЕ каждой `npm run build` + `postbuild.py`)

Сборка Astro перезаписывает `dist/index.html` старой версией, поэтому:

```bash
bash homepage-static/apply.sh
```

## Долг
Дизайн главной НЕ перенесён в исходники Astro (`site/src/pages/index.astro`).
При следующей итерации главной — перенести, иначе сборка будет откатывать её на версию 11.11.
