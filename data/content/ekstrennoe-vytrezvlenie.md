## Препараты для вывода из алкогольной интоксикации

Течение наркологических болезней сопряжено с высоким риском появления состояний, которые могут быть жизнеугрожающими для пациента и его окружения. Для ликвидации таких ситуаций применяются экстренное вытрезвление и реанимационные мероприятия при позднем обращении в клинику.

Вывод человека из состояния алкогольного опьянения проводится с помощью медикаментозного лечения. Для него применяются:
- Инфузионная терапия для детоксикации организма. Для нее назначают физиологический и солевые растворы (трисоль, хлосоль и другие), тиосульфат натрия, калия, магния аспарагинат, раствор 5% глюкозы, раствор Рингера для внутривенного капельного вливания, унитиол для внутримышечного использования и кальция хлорид для введения в вену струйно. Применяются дегидратирующие препараты, такие как магния сульфат и маннитол для внутривенного введения или фуросемид для внутримышечного;
- Антиконвульсанты при судорожном синдроме: вальпроевая кислота, карбамазепин и другие;
- Антигипертензивные препараты для снижения артериального давления: магния сульфат, моксонидин, каптоприл и другие;
- Нейролептики для купирования психомоторного возбуждения: хлорпромазин, галоперидол и иные средства из соответствующей фармакологической группы;
- Гепатопротекторы на основе адеметионина для улучшения функционирования клеток печени - гепатоцитов;
- Витамины: цианокобаламин, пиридоксин, тиамин, аскорбиновая, тиоктовая, фолиевая кислоты и другие средства для избавления организма от свободных радикалов и поддержки нервной ткани;
- Транквилизаторы и снотворные препараты: диазепам, феназепам, тиопентал натрия и другие при повышенной возбудимости и тревожности;
- Ноотропы (нейрометаболические стимуляторы): внутривенное применение раствора пирацетама для защиты от гипоксии мозга.

Многие из перечисленных препаратов являются строго рецептурными и не могут быть приобретены в аптеке. Запрещено их самостоятельное применение на дому. Специалист клиники имеет набор необходимых препаратов с собой и все необходимое для введения лекарств (шприцы, капельные системы, антисептики, жгуты и иные расходные материалы). Оснащение бригады не уступает по эффективности помощи в стационаре.
