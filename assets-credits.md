# assets-credits.md — источники изображений

## Собственные материалы клиники (перенесены со старого сайта)

Все изображения на новом сайте — **оригинальные материалы клиники** с balashikha.neoplus-clinic.ru:

- `img/heroes/*.webp` — фоновые изображения страниц услуг (сжаты с ~1.3 МБ до ~28 КБ каждое, 1600px);
- `img/doctors/*.webp` — фото 7 врачей (фото А.М. Кунцева перекадрировано из круглой маски в квадрат);
- `img/gallery/*.webp` — фотогалерея клиники (16 фото, без изменений);
- `img/licenses/*.webp` — сканы лицензий Л041-01021-66/01009753;
- `img/reviews/*.webp` — аватарки авторов отзывов (проверены: часть битых на старом сайте заменена
  на инициал-плейсхолдер, а не на сток);
- `img/photos/*` — фото врачей/клиники из разделов «О клинике», «Врачи»;
- `img/logo.svg`, `img/logo-white.svg` — логотип «Балашихинский наркологический центр» (разработан в рамках проекта:
  марка — скруглённый квадрат с «плюсом» в фирменном градиенте + словесная часть шрифтами Manrope/Inter);
- `img/logo.png`, `img/favicon.png` — марка логотипа (favicon), сгенерированы программно;
- `img/og.webp` — OG-картинка, собрана из фото клиники (кроп 1200×630).

**Стоковые фотографии не использовались.** Полные оригиналы всех файлов — `assets/original/` (603 файла,
карта соответствия «старый URL → файл» в `assets/url-map.json`).
